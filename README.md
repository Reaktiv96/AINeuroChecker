# AINeuroChecker
Система автоматической проверки домашних заданий и генерации учебных кейсов. Приложение помогает преподавателям и кураторам быстро оценивать код студентов по заданным критериям и обучать AI-ассистентов на различных типах ошибок.

## ✨ Основные возможности

- **AI Проверка ДЗ**: Оценка решений студентов (Python/DS/AI) с использованием моделей GPT-4o/GPT-4 по 10-балльной шкале.
- **Глубокий анализ кода**: Проверка на критические ошибки (SyntaxError), логические несоответствия и поиск неоптимальных решений (например, использование циклов `for` там, где нужна векторизация `Pandas`/`Numpy`).
- **Генератор синтетических данных**: Автоматическое создание различных типов решений на основе эталонного кода:
    - ✅ **Perfect Alternative**: Правильные решения в другом стиле.
    - ❌ **Syntax Error**: Намеренно сломанный код для проверки реакции системы.
    - ⚠️ **Logical Error**: Код, который запускается, но дает неверный результат.
    - 🐢 **Non-Optimal**: Верный результат, полученный неэффективным способом.
- **Интеграция с Google Colab**: Автоматическая загрузка контента ноутбуков по ссылке.
- **Аналитика и логирование**: Отслеживание токенов, стоимости запусков (в рублях) и истории проверок.
- **Управление промтами**: Просмотр системных шаблонов для проверки и генерации.

## 🛠 Технологический стек
- **Frontend**: React 18, Vite, Tailwind CSS, Motion (анимации), Lucide React (иконки).
- **Backend**: Node.js, Express.
- **AI**: OpenAI API SDK (GPT-4o, GPT-4).
- **Инструменты**: Axios, Pyodide (для будущих проверок в браузере), FS-logging.

## Структура промптов
Приложение использует строго структурированные системные промпты, разделенные на этапы:
- **Технический аудит**: поиск синтаксических ошибок.
- **Логический анализ**: сверка с условиями задачи (<goal>).
- **Оценка оптимизации**: проверка использования векторизованных вычислений.
- **Персонализированный фидбек**: формирование ответа по принципу "+ - +".

## Мониторинг
Все запросы логируются в файл usage_logs.json. Система автоматически рассчитывает стоимость каждого запроса на основе затраченных токенов, что позволяет контролировать бюджет на AI.
