# Neuro-Checker v2.0 🤖

**Neuro-Checker** — это профессиональная система автоматизации проверки домашних заданий и автооптимизации промптов для направлений ИИ (AI, Data Science, Python, Машинное обучение). Система имитирует работу опытного куратора и методиста, анализируя код и решения студентов, выявляя логические, синтаксические и архитектурные ошибки, а также автоматически подгоняя промпты оценки под идеальную точность.

## 🚀 Ключевые возможности

### 1. 🔍 Интеллектуальный аудит и проверка Colab-ноутбуков
- **Загрузка решений по ссылке:** Автоматическое скачивание и парсинг файлов из Google Colab, Google Drive и Яндекс.Диска.
- **Широкий спектр форматов:** Поддержка файлов `.ipynb`, `.py`, `.txt`, `.md`, `.docx`, `.zip`, `.7z`.
- **Глубокий анализ кода:** Проверка логики, векторизации вычислений, архитектуры нейросетей, предобработки данных и корректности обучения.
- **Конструктивный фидбек:** Формирование развернутых ответов студенту по методу «+ – +» с указанием конкретных строк и рекомендаций по исправлению.

### 2. ✂️ Модуль сокращения и инжиниринга промптов (Prompt Compressor)
- **Преобразование ДЗ в Task Definition:** Быстрое сжатие развернутых материалов курсов и описаний заданий в лаконичные, структурированные промпты для LLM.
- **Библиотека шаблонов:** Встроенные методические образцы («Критериальный промпт с баллами», «Выявление критических багов», «Идеальный код») с возможностью создания и сохранения пользовательских шаблонов.
- **Методическая аналитика:** Расчет процента сжатия текста, количества символов и развернутые пояснения от AI-методиста.

### 3. 🎯 Циклическая автооптимизация промптов (Prompt Tuner / GPT Judge)
- **Автоматическая подгонка точности:** Пошаговое улучшение формулировок задания с помощью нейросетевого судьи (GPT-5.4 Judge) до достижения минимальной ошибки оценивания.
- **Умная подготовка тестовых кейсов:** Автоматический учёт заданного количества успешных (Pass) и ошибочных (Fail) работ с возможностью принудительной перегенерации из меню.
- **Результативный модальный интерфейс:** По завершении оптимизации итоговый промпт выводится в отдельном удобном модальном окне с показом статистики (итерации, MAE, точность) и кнопками моментального копирования или использования в проекте.

### 4. 📊 Сравнительная аналитика и пакетная проверка (Batch Benchmark)
- **Сравнение версий промптов:** Одновременная или последовательная проверка работ несколькими вариантами промптов для поиска наилучшей формулировки.
- **Интерактивные графики (Recharts):** Визуализация показателей корреляции Пирсона, средней абсолютной ошибки (MAE) и сопоставления «План vs Факт» (Plan vs Fact Grade).
- **История прогонов (Runs History):** Сохранение всех сессий проверок, параметров и результатов с возможностью загрузки в любой момент.

### 5. 📑 Экспорт отчетов и финансовый мониторинг
- **Экспорт в Excel (.xlsx):** Детальные таблицы со всеми оценками, вердиктами, ссылками на решения и пояснениями.
- **Учет токенов и стоимости:** Точный расчет расходов (Prompt Tokens, Completion Tokens, Cost $) по каждому запросу к OpenAI API.

## 🛠 Технологический стек

- **Frontend:** React 18, Vite, Tailwind CSS, Lucide Icons, Recharts, Motion (Framer Motion).
- **Backend:** Express (Node.js), OpenAI API SDK (GPT-4o, GPT-4o-mini, o1-mini).
- **Code Execution:** Pyodide (Python в браузере) для изоляции и тестирования кода.
- **Persistence:** LocalStorage для секретов, пользовательских шаблонов и сохраненных запусков.

## 📖 Порядок работы с приложением

1. **Задайте параметры эталона:** Укажите тему задания и вставьте ссылку на Google Colab с правильным решением преподавателя.
2. **Сгенерируйте или введите Task Definition:** Используйте инструмент **«Сокращение промпта»** (Prompt Engineering) или введите критерии проверки вручную.
3. **Настройте состав тестовых кейсов:** Выберите количество успешных (Pass) и неисправных (Fail) работ, укажите интересующие типы ошибок.
4. **Запустите пакетную проверку или Автооптимизацию:**
   - *Batch Check* — для комплексного оценивания работ текущими промптами.
   - *Auto-Optimize Prompt* — для автоматической настройки промпта под минимальную ошибку.
5. **Анализируйте результаты и экспортируйте данные:** Изучайте графики корреляции/MAE, просматривайте итоговые промпты в всплывающих окнах и скачивайте сводные отчёты в Excel.

## 🔐 Безопасность (User Secrets)

Все API-ключи OpenAI сохраняются в зашифрованном виде в `localStorage` вашего браузера и передаются исключительно в заголовках безопасных запросов. Это обеспечивает защиту общего баланса и позволяет использовать приложение публично.
