# AINeuroChecker
Система автоматической проверки домашних заданий и генерации учебных кейсов. Приложение помогает преподавателям и кураторам быстро оценивать код студентов по заданным критериям и обучать AI-ассистентов на различных типах ошибок.

## ✨ Основные возможности

- **Автоматическая проверка Colab-ноутбуков:** Загрузка кода напрямую по ссылке.
- **Интеллектуальная оценка:** Использование LLM (GPT-4o) для глубокого анализа логики и векторизации.
- **Генерация синтетических данных:** Возможность создавать "эталонные ошибки" для тестирования системы оценки.
- **Аналитика и метрики:** Расчет корреляции, MAE и точности автоматической проверки.
- **Интеграция с Excel:** Экспорт результатов проверки в удобные отчеты.
- **Безопасность:** Поддержка пользовательских секретов (API-ключей) для работы через личные аккаунты OpenAI.

## 📖 Как пользоваться

🔗 [Ссылка на приложение](https://ai-homework-checker-313679939578.europe-west2.run.app/)

1. **Укажите эталон:** Вставьте ссылку на Google Colab с правильным решением.
2. **Опишите задание:** В поле "Task Definitions" укажите промпт для ИИ (что именно нужно проверить).
Ожидаются файлы по ссылкам общего доступа с Яндекс Диск или Google Диск
Список поддерживаемых расширений файлов: '.ipynb', '.py', '.txt', '.md', '.docx', '.zip', '.7z'
4. **Настройте кейсы:** Выберите количество и типы генерируемых кейсов для тестирования.
5. **Запустите проверку:** Нажмите кнопку "Start Batch Check" и дождитесь завершения анализа.
6. **Экспорт:** Скачайте результаты в формате Excel для дальнейшей работы.



## 🛠 Технологический стек
- **Frontend**: React 18, Vite, Tailwind CSS, Motion (анимации), Lucide React (иконки).
- **Backend**: Node.js, Express.
- **AI**: OpenAI API SDK (GPT-4o, GPT-4).
- **Инструменты**: Axios, Pyodide (для будущих проверок в браузере), FS-logging.

## Структура промптов
Приложение использует строго структурированные системные промпты, разделенные на этапы:
- **Технический аудит**: поиск синтаксических ошибок.
- **Логический анализ**: сверка с условиями задачи (<goal>).
- **Оценка оптимизации**: проверка использования векторизованных вычислений.
- **Персонализированный фидбек**: формирование ответа по принципу "+ - +".
 
## Мониторинг
Все запросы логируются в файл usage_logs.json. Система автоматически рассчитывает стоимость каждого запроса на основе затраченных токенов, что позволяет контролировать бюджет на AI.
